# Blender / Unity
相變らずほとんど觸らず。天袋・地袋を少し觸ったが、箱を構築したはいいものの、２つ並んだ引き戸風にするところで面倒臭くなってしまった。敢へてProceduralにすべきでないことまで、遠囘りしてしまっている感はある。
# 小説
趣味で書いている。とても人には見せられないが、物語創作理論とかを考へるのがもともと好きで、むしろそこが興味の主眼となってゐる。いつまでたっても完成しない全て５章構成のへぼ小説ながら、今回構成に関して新しい発想があって、少し嬉しい。
そして小説の推敲で使っている創作の手法にとても可能性を感じてゐる。NotebookLMやChatGPTに、作品の概要や概念、キャラクターの設定や見た目、展開のインフォグラフィックを書かせるのだ。これは自分のモチベーション用でもあり、作品をブレなく完成させるためのガイドにもなると思っている。例へば「第一章の内容を１２コマの漫画で表現して」というと、漫画といふよりは紙芝居風に展開をまとめてくれて、客観的・俯瞰的な視点で物語が面白いかを整理することができるわけだ。
これはきっとゲーム創作（一應創作の本願のつもりだ）にも役立つだらう。

## 仕事のミスは防がなければ
つまらないミスのせいで多くの人にご迷惑をかけた。自身の生活にも影響があったし、信頼を損なったと思ふ。本當につまらないミスなのだけれど、うちの仕事場は「無難にやればオーケー、ただしミスはするな」といふ感じの雰囲気の減点方式だから、かうしたことの積み重ねは評価にも影響するだらう。出世なんて死んでも嫌なのでむしろ評価されたいわけではないのだが、ある程度の信頼と尊敬を得ることは必要なのである。
私はまず間違いなくADHDの雰圍氣があり（根拠なく断言すると實際に診断を受けていて、なおかつ苦しんでゐる人に失礼なのでぼかすが）、これにはずっと悩んでいたが、職場のルーチンを考へ直すべきだとつくづく思ふ。特にスケジュール管理は凄く重要だから、人一倍、あるいは倍くらゐは机周りの整理にあててもいいかもしれない。例へば終業前の３０分は整理に当てるとかね。
