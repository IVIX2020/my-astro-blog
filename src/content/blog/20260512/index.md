# Blender / Unity
久しぶりにGeometry Nodes周りを觸る。松を表現するべく、`Curve Line`などを使った植物の生成である。`Curve Tangent`を使ふのが、枝分かれの方向を揃える上でのコツのやうだ。基本的には枝葉は太陽の方を向かなきゃいけないから、その當りの自然さも自動で再現できる樣な仕組みまで持っていきたい。目指してゐるゲームでは植生もまた一つの登場人物と言へる。

# 小説やゲームのアイデアをNotebookLMで
設定や企畫書を`NotebookLM` や`Chat GPT`を使って生成することにハマっている。文字情報をインフォグラフィックにするわけだが、そのことによる利点は２つある。
 - 自分自身にとって意味がある。映像になって別りやすくなり、ゴールを明確にできる。
 - AIを活用する上で便利。情報のまとまり（特定の人物の設定、特定の角度からの分析）を画像単位で扱へるため、AIに提供する情報資源として扱いやすい。
AIは道具だと思ってゐるので、何かの創造的な企画を丸つ切り考へさせるとか、あるいは自分の考へを「學習させて第二の腦にする」なんてことは今では考へてゐないが、かういふ「視覚化」「言語化」といった情報のまとめにはガンガン使って行きたいと思ってゐる。

下はChat GPTを使ったものだが、現時点での頭の中をうまく書き出してくれてゐると思ふ。

## 動画で臺灣華語を学ぶ
`Rakuten KOBO`を使った學習も継続してゐるが、Youtube上の動画資源もかなり有用なので、最近は學習に使ってゐる。特に臺灣人が残したであろうコメント欄（留言欄，留言區）の文章が役に立ち、自然な表現が學べると思ってゐる。臺灣人が投稿した動画で面白いのがあれば動画自体から文章を學べていいのだが、残念ながら今見てゐる動画は在臺日本人のものが中心なので、リスニングを學ぶのにもあまりよくはないと思ふ。このあたりいいYoutuberを見つけられたらいいなと思ふ。

## 再度山公園でワインと食事を楽しむ
今週はこれが最高だった。ワインもなかなか美味しく（スペインはカタルーニャ州のAmberワイン）、料理も突貫工事的に拵へた割には上々の出來で、ワインともよくあった。作ったのは以下の品。

 - タコとオレンジと新玉ねぎのサラダ
 - バルバコア
 - 豚肩肉リエット
 - パプリカのマリネ
 - アスパラガスと味噌ディップ

クラッカーとコーントルティーヤを持って行って、氣樂に手で摘みながら食べる。本當にかういふのがいい時間だし、幸せだと思ふ。たまたま喫茶店（再度山公園にはさういふのがある）でライブにも鉢合わせてそれも良かった。
